Una
===

In 'Una', I explored the fundamental dimensions of color, shape, and texture. With a hand-drawn approach, I sought to imbue the artwork with a palpable texture, enriching it with depth and genuine character. My intent was to showcase the inherent simplicity found in both composition and hue.

Una is made in go without a framework.

Controls
--------
The controls are as follows:
- Press `s` - 450 x 650 png output
- Press `1` - 900 x 1300 png output
- Press `2` - 1800 x 2600 png output
- Press `3` - 3600 x 5200 png output
- Press `4` - 7200 x 10400 png output
- Press `5` - 9000 x 13000 png output


Please note that the larger the output, the longer it will take to generate.
