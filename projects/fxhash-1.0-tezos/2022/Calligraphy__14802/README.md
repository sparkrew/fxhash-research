Calligraphy is about formulating letters, not language. 

One of my first exercises as graphic design student (c. 1967) was learning to letter. Using a nib holding pen and India ink we sat for 5 weeks in class like monks constructing letters in the style of a font called 15th Century Chancery Italic Script. Our final grade was based on how well we hand lettered a paragraph. It was a grueling process that's why I remember it; quite the way to develop an appreciation for the letterforms and type faces. 

This algorithmic artwork is modern cuneiform. It is based on a theory I've developed called "Language of Vision" which in itself is an approach for creating a "plastic" image. The space-frame or background square consists of a subtle paper texture and defines the tablet. A resizable tile (spatial force) forms the boundary for a "stroke." The stroke within the tile element is created by joining two bezier curves. 

An algorithm called "fractions of the whole" is a "form of spatial organization" which divides the picture frame into randomly sized intervals along each axes that form the variable sized tile areas. The stroke is programmed to fit each area. This theory leads itself very nicely to algorithmic art and provides a general framework for generative art.

There is meaning in every image but that meaning comes from your experience and imagination.
